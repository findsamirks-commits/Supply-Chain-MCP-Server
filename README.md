# Enterprise Supply Chain MCP Server 📦🔌

An enterprise-grade **Model Context Protocol (MCP)** server providing secure, structured access to retail ERP data over standard `stdio` using **FastMCP** (official `mcp` SDK) and **SQLite3**.

Designed to empower autonomous agent architectures (Claude Desktop, Cursor, Antigravity IDE, LangGraph pipelines, and OpenAI agent runtimes) with real-time dark-store inventory visibility and vendor fulfillment lead-time intelligence.

---

## 🛠️ MCP Tool Definitions

### 1. `get_inventory_level(sku: str, dark_store_id: str) -> str`
Queries live stock counts from the `inventory` table and returns status flags (`HEALTHY`, `LOW_STOCK`, `CRITICAL_OOS`) and replenishment recommendation triggers.

**Example Tool Output:**
```json
{
  "sku": "SKU-AMUL-BUTTER-500G",
  "dark_store_id": "DARKSTORE-DELHI-SOUTH-01",
  "stock_level": 142,
  "status": "HEALTHY",
  "reorder_recommended": false
}
```

### 2. `get_vendor_lead_time(vendor_id: str) -> str`
Queries supplier delivery performance from the `vendor_lead_times` table, returning category specialization and replenishment SLA urgency (`RAPID_DISPATCH` vs `STANDARD_DISPATCH`).

**Example Tool Output:**
```json
{
  "vendor_id": "VENDOR-AMUL-DIRECT",
  "category": "Dairy & Spreads",
  "lead_time_days": 2,
  "dispatch_sla": "RAPID_DISPATCH"
}
```

## 🚀 Quick Start

### 1. Installation
```bash
git clone https://github.com/findsamirks-commits/Supply-Chain-MCP-Server.git
cd Supply-Chain-MCP-Server
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

### 2. Initialize the ERP Database
```bash
python database_setup.py
```

### 3. Run Self-Test Verification
```bash
python client_test.py
```

### 4. Run the MCP Server over Stdio
```bash
python server.py
```

## 🔌 Connecting to MCP Clients

### Claude Desktop Configuration
Add the following to your `claude_desktop_config.json` (located at `%APPDATA%\Claude\claude_desktop_config.json` on Windows or `~/Library/Application Support/Claude/claude_desktop_config.json` on macOS):

```json
{
  "mcpServers": {
    "retail-supply-chain": {
      "command": "python",
      "args": [
        "c:/Users/Samir/Downloads/REPO/Supply-Chain-MCP-Server/server.py"
      ]
    }
  }
}
```

### Antigravity / Cursor IDE Configuration
In your project or workspace `.gemini/antigravity-ide/mcp_config.json`:

```json
{
  "mcpServers": {
    "retail-supply-chain": {
      "command": "python",
      "args": ["c:/Users/Samir/Downloads/REPO/Supply-Chain-MCP-Server/server.py"],
      "transport": "stdio"
    }
  }
}
```
